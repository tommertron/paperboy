PAPERBOY

Your Instapaper unread list and Feedbin starred articles on this reader. Needs a Paperboy server: https://coefficiencies.com/apps/paperboy/

SETUP: put the reader in File Transfer mode, open http://crosspoint.local, find the Paperboy card under Settings, enter your server URL and token, tap Test connection, then Save. Restart the reader.

USING IT: pick an article to download it to /Paperboy. The first row of each list, Sync all, downloads every article not already on the reader; afterwards use Refresh library in the Library.

FINISHED ARTICLES are archived in Instapaper (or unstarred in Feedbin) the next time the reader is on Wi-Fi.

TIDY-UP: while the reader is in File Transfer mode on the same network as the server, archived articles are removed from the reader and new ones added. Only articles Paperboy downloaded are touched.
